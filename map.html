A Cafe I Recommend

This page uses the Google Maps JavaScript API to show HamHamPangPang, a themed cafe in Suwon, South Korea, run by the game studio Project Moon. It is the same studio behind the games that all three Mili songs on my video profile page were written for. The map below is interactive, so you can pan, zoom and switch between the map and satellite views.

What makes it worth recommending is that the cafe rebuilds itself around whichever game the studio is promoting at the time. The menu, the decorations and the music playing inside all change with the theme, so going back a year later is not the same visit twice. That is also the problem. As the games picked up a larger audience the reservations got much harder to land, and the popular themes book out quickly. I keep going anyway.

Using The Map

Three things were added to the basic map from the Google documentation, so there is more to do here than pan and zoom:

  • The marker sits on the cafe itself rather than on the neighbourhood, so you can see exactly which building to walk to
  • Click that marker and an info window opens with the name and the street address
  • The shaded red circle covers the block the cafe sits on, which is about a two minute walk across
